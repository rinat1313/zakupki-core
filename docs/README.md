# API documentation

OpenAPI 3.0 спецификация: [`openapi.yaml`](./openapi.yaml)

Каноническая копия для runtime (embed): `internal/httpapi/openapi.yaml`.
При изменении API обновляйте **оба** файла.

После запуска сервиса:

- Swagger UI: `http://localhost:8080/swagger/`
- Spec: `http://localhost:8080/api/openapi.yaml`
